# Կենսագրություններ

Յուրաքանչյուր պրոֆիլի կենսագրությունը պահվում է առանձին TypeScript ֆայլում։
Ֆայլի ձևաչափը՝ `Name_Surname_Biography.ts`։ Անունն ու ազգանունը սկսվում են մեծատառով, բառերը բաժանվում են ընդգծումով։ Կեղծանունները պահպանվում են՝ օրինակ `Raffi_Biography.ts`, `Siamanto_Biography.ts`։

`index.ts`-ը կենսագրությունները կապում է պրոֆիլների հաստատուն նույնացուցիչներին։ `data/content.ts`-ը դրանք միավորում է հիմնական կատալոգին։ Էջերի և գործերի հասցեները չեն փոխվում։

Գրառման մեջ պահվում են ներածությունը, թեմատիկ բաժինները, ժամանակագրությունը, աղբյուրի հղումը և ներբեռնվող DOCX-ի հասցեն։ DOCX-ները գտնվում են `public/biography/` պանակում։ Վեց սկզբնական կենսագրությունները հիմնված են օգտատիրոջ տրամադրած փաստաթղթերի վրա, մյուս 96-ը խմբագրված նյութեր են՝ յուրաքանչյուր գրառման մեջ նշված տեղեկատուով։

Վիճելի կամ անհայտ ամսաթվերը նշել մոտավոր կամ դարով։ Չավելացնել չհաստատված ընտանիքի, մահվան կամ պարգևների մանրամասներ։ Նոր կենսագրությունը ավելացնել նաև `index.ts`-ում և ստուգել՝ `npm run test:people`։
