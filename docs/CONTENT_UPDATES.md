# Օգտատիրոջ նոր հանրագիտարանային նյութերի ինտեգրում

| Բաժին | Բազայում պահված հարցեր | Նոր խորացված բացատրություններ | Մոտեցում |
|---|---:|---:|---|
| Գրականություն | 58 | 4 | Նոր հավաքածուն փոխարինում է ակտիվ ցանկին։ Հին 48 հոդվածները պահպանված են lazy արխիվում։ |
| Առողջություն | 84 | 10 | Նոր հավաքածուն փոխարինում է ակտիվ ցանկին։ Հին 44 հոդվածները պահպանված են lazy արխիվում։ |
| Ֆինանսներ | 122 | 5 | Ֆայլի ցուցման համաձայն՝ 70 նոր հարցը ավելացված է գործող 52-ին։ Բոլոր հին ID-ները պահպանված են։ |

Օգտատիրոջ վերջին ցուցումով՝ երեք բաժիններում ցուցադրվում է միայն 10-ական հարց։ Ընտրվում են մանրամասն բացատրության, բաժինների, օրինակների և եզրահանգման ամենամեծ ընդհանուր տեքստային ծավալ ունեցող նյութերը։ Մնացած հարցերն ու բոլոր հղումները պահված են՝ հետագայում ընդլայնելու համար։ Որոնումը ներառում է ընտրված նյութերի ամբողջ բացատրությունը։ Մյուս առարկաների ընտրության կանոնները չեն փոխվել։

`data-test`-ում գտնվող վեց սկզբնական ֆայլերը չեն խմբագրվել կամ ջնջվել։ Գործող օրինակները `data/encyclopedia`-ում են և կապված են ընդհանուր enrichments-ի հետ՝ մյուս առարկաների բացատրությունները պահպանելով։

Ֆինանսի մեկ կապ ուղղված է միայն ինտեգրված պատճենում. `finance-credit-5-b`-ի բացատրությունը վերաբերում էր փոքր ամսական վճարմանը, բայց այդ ID-ն ուշացման պայմանների մասին է։ Բացատրությունը կցված է իրական համապատասխան հարցին՝ `finance-credit-6-b`։ Տեքստը չի փոխվել։

Հին գրականության և առողջության հոդվածների URL-ները դեռ բացվում են, և հին պահպանումները վերականգնում են վերնագիրը «Իմ FACTUM»-ում։ Արխիվները ներառված չեն ընդհանուր ակտիվ կատալոգում. բեռնվում են միայն համապատասխան հին URL կամ պահպանում բացելիս։

Ստուգումներ՝ `npm run test:content` (18 ստուգում), `npm run typecheck`, `npm run build:vercel`, `git diff --check`։ Թեստերը ստուգում են նաև բոլոր 44 հին առողջության URL-ները, նոր որոնումը, տասական ընտրությունը և հին պահպանումների վերականգնումը։
