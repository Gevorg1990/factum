# FACTUM-ի հրապարակումը

Նախագիծը հրապարակվում է Vercel-ում՝ Nuxt-ի սերվերային գործառույթներով։
GitHub պահոց՝ https://github.com/Gevorg1990/factum

## Առաջին հրապարակումը

1. Փոփոխությունները ուղարկիր GitHub-ի `master` ճյուղ։
2. https://vercel.com/new էջում մուտք գործիր GitHub-ով և ներմուծիր
   `Gevorg1990/factum` պահոցը։
3. Հաստատիր `Nuxt.js` framework-ը, նախագծի արմատային պանակը և Node.js 24-ը։
   `vercel.json`-ը կարգավորում է `npm ci` տեղադրումն ու `npm run build:vercel` build-ը։
4. Environment Variables բաժնում լրացրու միայն սերվերի համար նախատեսված տվյալները՝

   ```env
   NUXT_AZURE_SPEECH_KEY=քո_Azure_Speech_բանալին
   NUXT_AZURE_SPEECH_REGION=քո_ծառայության_տարածաշրջանը
   ```

   Բանալին մի տեղադրիր GitHub-ում, `vercel.json`-ում կամ `NUXT_PUBLIC_` փոփոխականում։
   Տեղական `.env`-ը Git-ի և հրապարակման արդյունքի մաս չէ։

5. Սեղմիր Deploy։ Ավարտից հետո Vercel-ը կտա կայքի իրական HTTPS հղումը։
6. GitHub պահոցի About → Website դաշտում ավելացրու ստացված հղումը։
   Production Branch-ը պետք է լինի `master`, որ հետագա push-երը հրապարակվեն ավտոմատ։

## Ընտրովի՝ AI բացատրություններ

1. Բացիր [OpenAI API Keys](https://platform.openai.com/api-keys) էջը և ստեղծիր API key։
2. Vercel-ի Project → Settings → Environment Variables բաժնում ավելացրու
   `NUXT_OPENAI_API_KEY` փոփոխականը և ընտրիր Production միջավայրը։ Բանալին
   պահիր որպես գաղտնի արժեք. այն մի ուղարկիր GitHub կամ չաթ։
3. Պահպանիր փոփոխականը և Redeploy արա վերջին deployment-ը։ Նախորդ deployment-ները
   նոր փոփոխականը չեն ստանում։

Տեղական `.env`-ում շարունակում է գործել `OPENAI_API_KEY` անունը։ ChatGPT-ի
բաժանորդագրությունը API-ի օգտագործման վճարը չի ներառում․ API-ի billing-ը առանձին է։
Կարգավորիր API նախագծի ծախսի սահմանաչափ կամ ծանուցում, քանի որ բացատրությունների
հարցումները սերվերից կատարվում են յուրաքանչյուր օգտագործողի համար։

Առանց Azure-ի տվյալների կայքը կբացվի, իսկ հայերեն ընթերցման բլոկը կհայտնի,
որ ձայնային ծառայությունը դեռ միացված չէ։ Բանալիները հետո ավելացնելու դեպքում
պետք է կատարել Redeploy։

## Ստուգումներ

Տեղական հրապարակման build՝ `npm run build:vercel`։ Արդյունքը՝ `.vercel/output/`։
Սա պարունակում է և՛ ստատիկ ֆայլերը, և՛ Nuxt-ի սերվերային ֆունկցիան։
Ստատիկ `nuxt generate` տարբերակը չի ապահովում մեր սերվերային ձայնային API-ները։

Հրապարակումից հետո ստուգիր գլխավոր էջը, վիդեոների preview-ն, որոնումը,
հայտնի մարդու կենսագրության ընթերցումը և երկու ձայնային խաղերը։
Խաղերում միկրոֆոնի օգտագործումը պահանջում է այցելուի բրաուզերի թույլտվությունը։

Պաշտոնական ուղեցույց՝ https://vercel.com/docs/frameworks/full-stack/nuxt

## Արագության կարգավորումները

Գլխավոր էջը նախապես կառուցվում է որպես ստատիկ HTML և Vercel-ում սպասարկվում է
ստատիկ ֆայլերի միջոցով։ Որոնման և ձայնային ընթերցման API-ները մնում են սերվերային։
Գլխավոր էջի հղումների նախաբեռնումը կատարվում է միայն փոխազդեցության դեպքում։
Վիդեոները ներբեռնվում են միայն նվագարկում պահանջող hover/focus-ի ժամանակ։

Քարտերի 19 նկարների 640px WebP տարբերակները գտնվում են `public/images/optimized/`
պանակում։ Դրանց անունները պարունակում են բովանդակության hash, իսկ հասցեների
քարտեզը՝ `data/optimizedImages.ts` ֆայլում։ Սկզբնական JPG-ները պահպանված են։
Օպտիմալացված տարբերակները միասին մոտ 0.68 ՄԲ են՝ սկզբնական մոտ 13.7 ՄԲ-ի փոխարեն։
Բովանդակության hash-ով նկարների համար միացված է երկարատև CDN cache-ը։

Բրաուզերի կատալոգը ներմուծում է միայն հրապարակված մարդկանց կենսագրությունները՝
`data/publishedBiographies.ts` ֆայլից։ Ամբողջ արխիվը պահպանված է առանձին։
